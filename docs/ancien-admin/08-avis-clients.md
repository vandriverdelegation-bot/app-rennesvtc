# Avis clients

**Chemin** : Avis clients
**URL** : `/avis`

## En-tête
- Bouton **Réglages des avis**.
- Guide : "Communiquer avec vos clients".

## Statistiques
- Note moyenne globale (ex: 5,00) + total d'avis.
- Répartition par nombre d'étoiles (5 lignes : 5★ à 1★, avec compteur pour chacune).
- **Moyenne par mois** : sélecteur d'année, puis détail par mois (ex: "Février — 5,0 — 3 avis").

## Filtres
- Chauffeur (tous ou un en particulier)
- Date de début / Date de fin
- Trier par (ex: Plus récents)
- Bouton Réinitialiser

## Vue liste
Tableau : **NOTE** (étoiles), **CLIENT / CHAUFFEUR** (noms + emails), **DATE**, **RÉSERVATION** (date + trajet départ/arrivée, lien "Voir la réservation").
Pagination.
