# Marketing (5 sous-pages)

## Codes promo
**URL** : `/code-promo`
- Bouton **Ajouter un code promo**.
- Section "Historique" : tableau **CODE PROMO**, **CLIENT**, **RÉSERVATION**, **DATE D'UTILISATION**, **ACTIONS**.
- Guide lié : "Codes promo et programme de fidélité".

## Fidélité
**URL** : `/fidelite`
- Activation globale du programme (toggle Activé/Désactivé).
- **Design de la carte fidélité** (aperçu mobile en temps réel) :
  - Nom du token
  - Icône (choix parmi ⭐💎🪙👑❤️🔥🚗✨🎁🏆💫🌟)
  - Couleur principale / secondaire (+ préréglages)
  - Style de carte : Dégradé / Uni / Verre / Vague / Points / Diagonal
  - Disposition : Classique / Inversé / Compact
  - Éléments affichés : cercles décoratifs, lien "Voir tout", prochaine récompense, description
- **Règles de gain** : points par € dépensé (ex: 1 PTS/€), bonus 1ère course, expiration des points (en mois, vide = jamais).
- **Récompenses** : liste (+ Ajouter), vide par défaut.

## Notifications (= Campagne de notifications mobile)
**URL** : `/campagne-notifications`
- Bouton **Créer une campagne**. Limite : 1 campagne toutes les 2 heures.
- Historique des campagnes envoyées : titre, message, date/heure, nombre et liste de destinataires.
- **Formulaire de création** :
  - Titre (5-35 caractères, compteur)
  - Message (25-100 caractères, compteur)
  - **Envoyé à** : sélection multiple parmi 2 listes avec pagination — **Clients** (tout sélectionner/désélectionner, recherche) et **Chauffeurs secondaires** (idem)
  - Boutons Fermer / Envoyer

## Pop-up de bienvenue
**URL** : `/pop-up-bienvenue`
- Deux pop-up séparées : **Chauffeurs** et **Clients**, chacune activable/désactivable.
- Message affiché une seule fois après inscription, avec texte riche (texte, images, liens).

## Annonces
**URL** : `/annonces`
- Bannières affichées sur l'accueil de l'app mobile.
- Bouton **Nouvelle annonce**. Liste vide testée (pas de formulaire ouvert).
